# Схемы регламента и памятки

Формат — `.drawio.svg`: обычная картинка SVG (её показывают GitHub, браузер, любой просмотрщик),
внутри которой лежит исходник схемы draw.io. Отдельных исходников нет.

**Как править.** Открыть файл в draw.io — в приложении (https://www.drawio.com), на сайте
app.diagrams.net или в VS Code с расширением «Draw.io Integration» (`hediet.vscode-drawio`),
поправить и сохранить в тот же файл. Картинка обновится сама.

**Единый стиль** — держать при правке:

| Что | Цвет: заливка / рамка |
|---|---|
| Исполнитель | `#EAF2FB` / `#2F6FB3` |
| GitHub (автоматика) | `#F3F4F6` / `#6B7280` |
| Владелец | `#F1ECFA` / `#6B4FA3` |
| Можно, готово | `#E3F4E8` / `#2E8B57` |
| Ждать | `#FFF4D6` / `#B98900` |
| Нельзя | `#FDE4E1` / `#C0392B` |
| Нейтральный блок, вопрос | `#FFFFFF` / `#9CA3AF` |

Шрифт Segoe UI 13, стрелки `#4B5563`. Подписи — без HTML-форматирования (в стиле `html=0`), фон
страницы белый: тогда SVG читается и в тёмной теме GitHub.
