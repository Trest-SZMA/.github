# Trest-SZMA/.github

Общие правила и шаблоны организации Trest-SZMA. GitHub подставляет их во все репозитории организации.

| Что | Где |
|---|---|
| Регламент работы с репозиториями | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Памятка «задача от начала до конца» | [ПАМЯТКА.md](ПАМЯТКА.md) |
| Шаблоны PR и issue | `.github/` |
| Общая проверка PR (вызывается из репозиториев) | `.github/workflows/pr-check.yml`, `scripts/pr_check.py` |
| Файлы, которые кладутся в каждый общий репозиторий | [для-репозитория/](для-репозитория/) |

Правит этот репозиторий владелец организации. Предложения — issue здесь или сообщение владельцу.
